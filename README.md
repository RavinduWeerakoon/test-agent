# Antigravity LangChain Chat Agent REST API

A lightweight, pure REST API for a LangChain Chat Agent built with **FastAPI** (Python). 

The agent is equipped with a custom **Safe Calculator** tool and a **Wikipedia Search** tool. It can evaluate math expressions, search Wikipedia, and perform multi-step reasoning. It supports both standard synchronous REST responses and real-time token streaming using Server-Sent Events (SSE).

---

## Features

- **Pure REST API**: Fully stateless, backend-only service. No frontend HTML/CSS assets.
- **Dual Response Modes**: Supports standard JSON response (`stream: false`) and SSE streaming (`stream: true`).
- **Chain of Thought Logs**: Streaming mode feeds tool execution updates (inputs/outputs) and tokens in real-time. Non-streaming mode returns details of executed tools in the JSON payload.
- **Stateless Chat Memory**: The client keeps track of conversation history and passes it with each request.

## API Documentation

### 1. Check Config
Checks whether the server has provider API keys configured.

* **URL**: `/config`
* **Method**: `GET`
* **Response Format**: `JSON`
* **Example Response**:
  ```json
  {
    "gemini_configured": true,
    "openai_configured": false
  }
  ```

---

### 2. Chat Endpoint
Submit a query to the LangChain Agent.

* **URL**: `/chat`
* **Method**: `POST`
* **Headers**: `Content-Type: application/json`
* **Payload Structure**:
  ```json
  {
    "message": "Required. The query to ask the agent.",
    "history": [
      {"role": "user", "content": "Previous prompt"},
      {"role": "assistant", "content": "Previous agent response"}
    ],
    "provider": "google",
    "apiKey": "Optional client-side API Key override",
    "stream": true
  }
  ```

#### Non-Streaming Mode (`stream: false`)
Returns a standard JSON object containing the text output and a list of tool invocations completed.

* **Example Response**:
  ```json
  {
    "content": "The birth year of Albert Einstein was 1879. Multiplying it by 2 yields 3758.",
    "tool_calls": [
      {
        "name": "search_wikipedia",
        "input": "Albert Einstein",
        "output": "Wikipedia Title: Albert Einstein\nSummary: Albert Einstein was a German-born theoretical physicist..."
      },
      {
        "name": "calculator",
        "input": "1879 * 2",
        "output": "3758"
      }
    ]
  }
  ```

#### Streaming Mode (`stream: true` - Default)
Returns a chunked Event Stream (`text/event-stream`). Events arrive line-by-line starting with `data: `.

* **Event Types**:
  1. `{"type": "token", "content": "..."}`: Real-time tokens generated by the LLM.
  2. `{"type": "tool_start", "name": "...", "input": "..."}`: Sent when a tool starts running.
  3. `{"type": "tool_end", "name": "...", "output": "..."}`: Sent when a tool completes.
  4. `{"type": "done"}`: Signals the end of the streaming session.
  5. `{"type": "error", "message": "..."}`: Sent if a failure is encountered.

## Installation & Setup

1. **Activate Virtual Environment**:
   ```bash
   source .venv/bin/activate
   ```
2. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and fill in either `GEMINI_API_KEY` or `OPENAI_API_KEY`:
   ```bash
   cp .env.example .env
   ```

---

## Running and Testing the API

### Start the API Server
```bash
python app.py
```
The server will run on `http://localhost:8000`.

### Verify using Programmatic Script
Run the helper verification script:
```bash
python test_api.py
```
This script calls `/config`, tests a non-streaming POST request (using the Calculator tool), and then tests a streaming POST request (using the Wikipedia tool) to display SSE output logic.

### Verify using Curl
1. **Config Check**:
   ```bash
   curl http://localhost:8000/config
   ```
2. **Non-Streaming Query**:
   ```bash
   curl -X POST http://localhost:8000/chat \
     -H "Content-Type: application/json" \
     -d '{"message": "What is (145 + 355) * 12?", "stream": false}'
   ```
